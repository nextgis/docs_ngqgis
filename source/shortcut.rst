Shortcut Manager
==================

Create a shortcuts toolbar to run external programs and open web pages directly from QGIS .

After installation Shortcut Manager will appear in the Plugins menu.

.. figure:: _static/shortcut_open_en.png
   :name: shortcut_open_pic
   :align: center
   :width: 18cm

   Shortcut Manager in the Plugins menu

* Activate the plugin and press **Create shortcut**.

.. figure:: _static/shortcut_new_en.png
   :name: shortcut_new_pic
   :align: center
   :width: 8cm

   Plugin UI
   

* Select an app from your desktop, enter a path to a file on your device or a URL.

.. figure:: _static/shortcut_select_en.png
   :name: shortcut_select_pic
   :align: center
   :width: 7cm

* Enter a name for the shorcut button.

.. figure:: _static/shortcut_name_en.png
   :name: shortcut_name_pic
   :align: center
   :width: 7cm

* Select the icon.

.. figure:: _static/shortcut_icon_en.png
   :name: shortcut_icon_pic
   :align: center
   :width: 8cm

* Press **Finish**.

The shortcut button will appear on the Plugins toolbar.

You can edit and delete the shortcuts.

.. figure:: _static/shortcut_list_en.png
   :name: shortcut_list_pic
   :align: center
   :width: 8cm

   List of shortcuts
